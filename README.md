# CV — minimalist ATS-friendly resume

A dependency-free, browser-only CV builder. The CV itself is the front page.

- **Edit details** opens a quick-edit panel covering every field (contact, summary, experience, education, skills, projects, certifications, personal details).
- Everything updates live and autosaves to this browser via `localStorage`.
- **Download** exports the CV as **PDF** (text-based, ATS-friendly via browser print), **PNG**, or **JPG**.
- The CV layout is a single column with standard section headings, so applicant tracking systems can parse it cleanly.

Open `index.html` directly in a browser. No build step, no dependencies.
